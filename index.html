Mobile Application & Game Development

Building useful and engaging mobile experiences.

MAYDIUM is a South Korean software development business focused on developing and publishing Android mobile applications and games.

About MAYDIUM

MAYDIUM develops and publishes mobile applications and games with a focus on practical utility, accessible user experiences, and engaging gameplay. The company is registered in Seoul, Republic of Korea, as an application software publishing business.

Mobile Applications

Utility, productivity, lifestyle, and everyday applications designed for smartphone users.

Mobile Games

Casual and interactive mobile games designed for accessible and enjoyable gameplay.

Android Development

Android applications developed and maintained for distribution through major mobile application stores.
